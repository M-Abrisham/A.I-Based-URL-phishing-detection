# Data

Training data is not committed to the repo (too large).

## Source
[Kaggle — Web Page Phishing Detection Dataset](https://www.kaggle.com/datasets/shashwatwork/web-page-phishing-detection-dataset)

## Setup
1. Download `phishing_site_urls.csv` from the Kaggle link above.
2. Place it at `data/raw/phishing_site_urls.csv`.

## Layout
- `raw/` — original downloaded datasets, never edited.
- `processed/` — cleaned/feature-engineered outputs from training runs.
